
# KRYLA — Платформа цивільних безпілотних технологій

**KRYLA** — вебплатформа для ознайомлення з цивільними безпілотними літальними апаратами, порівняння їхніх характеристик, керування персональним ангаром та інтерактивного моделювання польоту дрона.

Проєкт розроблено на **Python та Django** як підсумкову навчальну роботу з веброзробки.

## 🚀 Основні можливості

- **Каталог дронів** — перегляд моделей, характеристик і категорій.
- **Пошук, фільтрація та сортування** — зручний вибір безпілотників.
- **Порівняння дронів** — зіставлення характеристик різних моделей.
- **Інтерактивний 3D-симулятор** — візуалізація польоту цивільного дрона у браузері.
- **Персональний ангар** — додавання, редагування та видалення власних записів про дрони.
- **Кошик** — вибір моделей і керування їхньою кількістю.
- **Оформлення замовлень** — створення та збереження замовлень.
- **Історія замовлень** — перегляд попередніх покупок.
- **Аналітика** — відображення статистичної інформації.
- **Обліковий запис** — реєстрація, авторизація та персональний профіль.

## ⚙️ Встановлення та запуск

### 1. Клонування репозиторію

```bash
git clone https://github.com/USERNAME/KRYLA.git
cd KRYLA
```

Замініть `USERNAME` на ім'я власника репозиторію GitHub.

### 2. Створення віртуального середовища

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Для Windows:

```bash
.venv\Scripts\activate
```

### 3. Встановлення залежностей

```bash
python -m pip install -r requirements.txt
```

### 4. Налаштування середовища

За потреби створіть файл `.env` у кореневій папці проєкту:

```env
DJANGO_SECRET_KEY=your-local-secret-key
```

Файл `.env` не додається до репозиторію.

### 5. Створення бази даних

```bash
python manage.py migrate
```

### 6. Заповнення каталогу

```bash
python manage.py seed_drones
```

### 7. Запуск сервера

```bash
python manage.py runserver
```

Після запуску відкрийте у браузері:

**http://127.0.0.1:8000/**

## 🔐 Безпека

- Секретні змінні зберігаються поза репозиторієм.
- Файл `.env` виключено з Git.
- Локальна база даних SQLite не публікується.
- Для персональних функцій використовується система автентифікації Django.
- Проєкт призначений для навчального та локального використання.

## 🎮 3D-симулятор

KRYLA містить інтерактивний симулятор польоту цивільного безпілотника, створений із використанням **JavaScript та Three.js**.

Симулятор є демонстраційною частиною вебплатформи та призначений для візуального ознайомлення з керуванням віртуальним дроном.
