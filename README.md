
# KRYLA — Платформа цивільних безпілотних технологій

**KRYLA** — інтерактивна вебплатформа для ознайомлення з цивільними безпілотними літальними апаратами, порівняння їхніх характеристик, керування персональним ангаром та моделювання польоту дрона.

Проєкт створено як підсумкову навчальну роботу з веброзробки на Python та Django.

## 🚀 Функціональні можливості

- **Каталог дронів** — 10 моделей із фотографіями, характеристиками та цінами.
- **Пошук і фільтрація** — пошук за назвою, фільтрація за категорією та доступністю, сортування.
- **Порівняння моделей** — зіставлення характеристик дронів.
- **3D-симулятор польоту** — інтерактивна тривимірна сцена на Three.js.
- **Персональний ангар** — додавання, перегляд, редагування та видалення записів.
- **Кошик** — додавання товарів і зміна кількості.
- **Оформлення замовлень** — створення замовлень зі збереженням у базі даних.
- **Історія замовлень** — перегляд оформлених замовлень.
- **Аналітика** — сторінка статистики.
- **Авторизація** — реєстрація, вхід, вихід та профіль користувача.

## ⚙️ Встановлення та запуск

### 1. Клонування репозиторію

```bash
git clone https://github.com/rarerock-hash/KRYLA.git
cd KRYLA
```

### 2. Створення віртуального середовища

Для macOS або Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Для Windows:

```powershell
python -m venv .venv
.venv\Scripts\activate
```

### 3. Встановлення залежностей

```bash
python -m pip install -r requirements.txt
```

Для роботи з Django 6.1 потрібна сумісна версія Python.

### 4. Налаштування секретного ключа

За потреби створіть файл `.env` у корені проєкту:

```env
DJANGO_SECRET_KEY=your-local-secret-key
```

Файл `.env` виключений із Git. Проєкт також підтримує автоматичне створення тимчасового ключа для локального запуску, якщо змінна не задана.

### 5. Створення бази даних

```bash
python manage.py migrate
```

### 6. Створення адміністратора

Перед заповненням каталогу потрібно створити користувача, якому належатимуть записи дронів:

```bash
python manage.py createsuperuser
```

Введіть ім'я користувача, електронну пошту (за потреби) та пароль.

### 7. Заповнення каталогу

```bash
python manage.py seed_drones
```

Команда автоматично створює 10 моделей цивільних дронів із характеристиками та фотографіями.

**Фотографії включені до репозиторію** в папці `drones/static/drones/images/`. Під час заповнення каталогу вони копіюються до локального сховища зображень Django.

Підключення до інтернету для завантаження фотографій не потрібне.

Команда не створює дублікати моделей і зберігає наявні фотографії.

За потреби можна вказати власника записів:

```bash
python manage.py seed_drones --username admin
```

Замініть `admin` на ім'я створеного користувача.

### 8. Запуск сервера

```bash
python manage.py runserver
```

Відкрийте у браузері:

**http://127.0.0.1:8000/**

## 🎮 Інтерактивний 3D-симулятор

У проєкті реалізовано інтерактивний симулятор польоту цивільного дрона з використанням JavaScript та Three.js.

Симулятор є демонстраційним навчальним інструментом і працює без підключення до фізичного безпілотника.

## 🔐 Безпека та доступ

- Реєстрація та авторизація реалізовані засобами Django.
- Персональні функції використовують облікові записи користувачів.
- Секретний ключ не зберігається у GitHub-репозиторії.

- Проєкт призначений для навчального та локального використання.
